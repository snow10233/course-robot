Privacy

隱私權政策

生效日期：2026 年 9 月 5 日

工具用途

Snowbox Course Sync 是由使用者自行管理的個人自動化工具，用來讀取課程安排，並在使用者指定的 Google Calendar 中建立、更新或刪除對應的課程行程。

存取的資料

  • Google Calendar 中由本工具管理的行程，包括標題、日期、時間、說明、地點與相關連結。
  • Google OAuth 存取憑證與更新憑證，用於維持使用者授予的 Calendar 存取權。
  • 來源課程平台提供的課程資料，例如上課時間、學生、章節、教材與線上教室資訊。

本工具不要求或存取 Gmail、Google Drive、Google 聯絡人、Google 文件或 Google 試算表資料。

資料用途與儲存

所有資料僅用於比對最新課程安排及同步 Google Calendar。OAuth 憑證、最新課程快照與行程對照資料保存在使用者自行管理的私人伺服器，不由本公開網站收集，也不會用於廣告或使用者分析。

資料分享

本工具不出售、出租或分享 Google 使用者資料給第三方。Google Calendar 資料只會傳送至使用者主動授權的 Google Calendar API。工具另行向課程來源平台取得課程安排，但不會將 Google Calendar 資料傳送至該平台。

保留與刪除

本工具僅保留最新課程快照、Calendar 行程對照資料及維持授權所需的 OAuth 憑證，不保存課程異動歷史。使用者可以刪除伺服器上的資料與憑證，並可從 Google 帳戶的第三方應用程式連線設定撤銷授權。

Google API 資料政策

本工具對 Google API 所取得資訊的使用與轉移，將遵守 Google API Services User Data Policy，包括 Limited Use 要求。
